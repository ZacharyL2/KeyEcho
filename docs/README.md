# KeyEcho app documentation map

Root is reserved for public project files such as `README.md`, `CHANGELOG.md`, license/security/community files, and build manifests.

| Destination          | Owns                                                 |
| -------------------- | ---------------------------------------------------- |
| `docs/guides/`       | User-facing durable guides such as custom sounds     |
| `docs/reference/`    | Public technical reference such as performance notes |
| `docs/architecture/` | Public architecture decisions when needed            |
| `docs/development/`  | Contributor-only setup and debugging guidance        |
| `docs/assets/`       | Documentation-only assets                            |

Private business, signing, provider, distribution, and deployment material belongs to the private companion or portfolio/platform authorities. Do not add AI handoffs, audits, or internal plans to this public repository.
